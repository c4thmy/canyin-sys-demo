## ADDED Requirements

### Requirement: 报告模板

系统 SHALL 内置「老板版」与「运营版」两套报告模板，每套模板 MUST 定义章节顺序、每章引用的指标与叙述语气。

#### Scenario: 查看报告模板

- **WHEN** 用户打开报告模板页
- **THEN** 页面列出两套模板及其章节目录

### Requirement: 报告生成

系统 SHALL 基于当前数据集、所选期间与报告模板生成章节化报告，每章 MUST 包含结论句、关键数字与配图。

#### Scenario: 生成老板版报告

- **WHEN** 用户选择期间 `2025-09` 与「老板版」并点击生成
- **THEN** 系统生成包含「执行摘要、利润桥、收入异动原点、三条行动建议」的报告，并出现在报告列表中

#### Scenario: 数字与页面一致

- **WHEN** 用户对比报告中的收入、营业利润与对应分析页面
- **THEN** 两者数值一致，允许的差异仅来自四舍五入

#### Scenario: 数据不完整时生成

- **WHEN** 当前数据集缺少某章节所需数据
- **THEN** 该章节显示「数据不足，本章略」，其他章节正常生成

### Requirement: 报告管理

系统 SHALL 列出已生成的报告（标题、模板、期间、数据集、生成时间），并支持查看与删除。

#### Scenario: 查看历史报告

- **WHEN** 用户在报告列表点击某份报告
- **THEN** 系统展示生成时的内容，不随之后的数据导入而改变

### Requirement: 报告导出

系统 SHALL 支持把报告导出为独立 HTML 文件，并提供适合浏览器打印为 PDF 的版式。

#### Scenario: 导出 HTML

- **WHEN** 用户点击「导出 HTML」
- **THEN** 下载一个离线可打开的 HTML 文件，图表以静态图片嵌入

#### Scenario: 打印 PDF

- **WHEN** 用户在报告预览页使用浏览器打印
- **THEN** 打印版式隐藏导航与按钮，每章从新页开始
