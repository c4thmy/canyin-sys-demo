# Spec Delta

## Purpose

定义 IM 渠道能力：用户通过飞书或微信向 Agent 团队下达需求、接收汇报，渠道之间共享同一套项目工作区与规格记录。

## ADDED Requirements

### Requirement: 多渠道路由

系统 SHALL 支持飞书与微信两个渠道，每个渠道的长连接独立，会话绑定到同一项目工作区。

#### Scenario: 飞书私聊下达需求

- **WHEN** 用户在飞书中私聊机器人并发送需求
- **THEN** 机器人把需求交给项目指挥官，正常开始处理

#### Scenario: 微信继续对话

- **WHEN** 用户在微信中继续同一项目的对话
- **THEN** 系统可读取同一份规格与任务记录，不重复询问背景

### Requirement: 访问控制

系统 SHALL 默认只响应本人，群聊中仅在机器人被 @ 时响应。

#### Scenario: 陌生人私聊

- **WHEN** 非授权账号私聊机器人
- **THEN** 机器人不执行任何指令

### Requirement: 进展可见

系统 SHALL 在飞书中显示任务过程，至少包括「正在处理」状态与最终答复。

#### Scenario: 长任务

- **WHEN** 一次需求处理超过 30 秒
- **THEN** 飞书中出现进度提示，用户知道系统仍在工作
