# 飞书接入步骤

本文件属于 change `add-feishu-channel`。按顺序执行，每步一两分钟。

## 前置

- 本机已安装飞书客户端并登录
- 你的飞书账号在该企业中有「创建应用」权限（管理员或开发者）

## 一、在 DSH 中添加飞书机器人

1. 打开 DeepSeek Harness → **设置** → **IM机器人**。
2. 选择 **飞书** 渠道。
3. 点 **扫码创建机器人**，用飞书 App 扫码。
4. 飞书会要求创建企业自建应用，按提示确认。
5. 回到 DSH，机器人出现在列表里，状态显示「已连接」。

> 已有应用的话，改写 App ID + App Secret 也可以。

## 二、配置机器人

在机器人卡片里设置：

| 项 | 建议值 |
|---|---|
| 工作区 | `~/.dsh/im`（默认） |
| 模型 | deepseek-flash |
| Agent Preset | 默认 |
| 私聊响应 | 仅本人 |
| 群聊响应 | 被 @ 时 |
| 任务过程展示 | 实时过程卡（投屏演示用） |

## 三、权限

扫码新建的应用默认申请了这些租户权限：

- `im:message.group_at_msg.include_bot:readonly` — 接收群内 @ 消息
- `im:message:readonly` — 读取单聊与群消息（收图片/文件用）
- `im:resource` — 上传图片与文件

如果提示缺权限，在机器人卡片点 **补全权限**，或私聊机器人发 `/repair`。

## 四、验证

1. 飞书私聊机器人，发「你好」，应收到回复。
2. 发「打开 openspec，告诉我现在有哪些 change 在进行」，应能读到 `add-revenue-analysis-demo`。
3. 建一个群，把机器人拉进去，@ 它提问，应能响应。

## 五、演示前检查

- [ ] 飞书 PC 端版本 ≥ 7.70（实时直播需要）
- [ ] 机器人状态为已连接
- [ ] 私聊与群聊各试一次
- [ ] 投屏分辨率下卡片文字可读

## 排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 扫码后无反应 | 企业不允许自建应用 | 找管理员开通，或改用 App ID + Secret |
| 私聊不回 | 访问策略只允许本人，账号不匹配 | 在机器人设置里加白名单 |
| 群里 @ 不回 | 缺群 @ 权限 | 点「补全权限」并完成飞书发布审批 |
| 长连接断开 | 网络或代理 | 检查代理设置，重启 Host |
