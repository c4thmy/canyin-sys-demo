# 收入分析模块 · 领域模型

从《利润桥及毛利率分析-高维第二期261003.xlsx》与《高维学堂经营分析与科学决策月度分析模版》提炼。
本文件是产品的事实来源：指标口径、拆解链路、页面结构都以此为准。

## 1. 月度经营分析的四步法

整个体系（收入、毛利、费用、顾客）共用同一套方法：

```
第一步  比差异      → 利润桥：营业利润同比，每个因素影响多少
第二步  找问题      → 收入/毛利结构分析 → 异动分析 → 锁定异动原点
第三步  定计划      → 针对根因给动作
第四步  达目标      → 一店一策、一品一策、督办清单
```

收入分析属于「第二步」展开，但它自带一条完整下钻链。

## 2. 收入分析的拆解链路（核心）

```
营业收入同比 +240 万
│
├─ 按「同店 / 新店」拆
│    新店 +143 万   ← 开店增量，看单店爬坡
│    同店 +97 万    ← 真正的经营增量，重点下钻
│
├─ 按「渠道」拆
│    美团大众 / 扫码支付 / 线上活动优惠 / 美团外卖 /
│    饿了外卖 / 抖音 / 会员储值 / 堂食现金 / 招商银行 / 京东外卖
│    每个渠道：收入、占比、同比差额、增减率
│
├─ 按「门店 / 区域」拆
│    区域 → 门店 → 收入排名 / 增长额排名
│
└─ 按「产品」拆
     系列（肉类/锅底/涮品/主食/凉菜/小料/饮品/其它）
       → 单品：销量、单价、收入、优惠
```

## 3. 异动分析：三个因素分解

收入 = 客流 × 客单价 = 客流 × 人均销量 × 产品单价

> **替换顺序（定稿）**：连环替代法一律**先替换量，再替换价**。
> 即先替换客流/销量，已替换的因素在后续步骤中改用本期值。
> 这与 Excel「营业利润连环替代法公式」页的说明一致：分析某因素时其他因素不变，
> 已经计算的因素，后面替换为本期数。

### 3.1 门店层（客流 vs 客单价）

```
收入差     = 客流差 × 上期客单价 + 本期客流 × 客单价差
客流影响   = 客流差 × 上期客单价
客单价影响 = 本期客流 × 客单价差
```

### 3.2 产品层（销量 vs 单价）

```
收入差   = 销量差 × 上期单价 + 本期销量 × 单价差
销量影响 = 销量差 × 上期单价
单价影响 = 本期销量 × 单价差
```

### 3.3 产品层（客流 × 人均销量 × 单价）

```
客流影响     = 客流差 × 上期人均销量 × 上期单价
人均销量影响 = 本期客流 × 人均销量差 × 上期单价
单价影响     = 本期客流 × 本期人均销量 × 单价差
```

> 口径统一：连环替代法。已经计算的因素，后面替换为本期数。参见 Excel「营业利润连环替代法公式」。

## 4. 渠道漏斗（线上收入专用）

```
曝光人数 → 访问人数 → 支付人数 → 消费人数
        转化率1      转化率2      转化率3
```

每个门店每月记录：曝光、曝光-访问转化、访问-支付转化、支付-消费转化、品牌顾客、新客、老客。

判断线上放量原因的公式：
- 平台费用率 ≤ 15%
- 线上 ROI = 平台毛利额 / 平台费用 ≥ 1
- 线上 ROI（销售额口径）= 平台销售额 / 平台费用 ≥ 4

## 5. 时间维度

| 口径 | 含义 |
|---|---|
| 本期 | 2025 年 9 月 |
| 上年同期 | 2024 年 9 月 |
| 预算 | 本期目标 |
| 模型值 | 业务参数标准（如人工成本率 22%、人效 4.5 万） |

对比是分析的核心：「和谁比」决定「看出什么」。

## 6. 关键指标字典

| 指标 | 公式 | 用途 |
|---|---|---|
| 营业收入 | 堂食 + 外卖 | 规模 |
| 单店日均营收 ADM | 收入 / 门店数 / 天数 | 单店健康度 |
| 客单价 | 收入 / 客流量 | 消费力 |
| 客流 | 消费人次 | 人气 |
| 折扣率 | 优惠额 / 原价额 | 促销力度 |
| 毛利率 | (收入 − 食材成本) / 收入 | 成本控制 |
| 边际贡献率 | (收入 − 变动成本) / 收入，变动成本 = 食材 + 优惠及手续费 + 水电气低值 + 宣传费用 | 增收的利润转化 |
| 翻台率 | 消费人次 / 餐位数 | 座位效率 |
| 坪效 | 收入 / 面积 | 选址效率 |
| 人效 | 收入 / 员工数 | 团队效率 |
| 会员消费占比 | 会员消费 / 总收入 | 用户资产 |

## 7. 利润桥（上下文，Demo 首页用）

```
营业利润 = 收入 × (毛利率 − 销售费率 − 税金率) − 固定成本
```

瀑布图因素：
收入规模 · 食材成本率 · 优惠及手续费 · 水电气低值 · 宣传费用 · 工资奖金 · 宿舍房租 · 店铺房租 · 其它费用

每个因素的影响额用连环替代法计算，颜色：上升绿、下降红、总额蓝。

### 7.1 变动成本与固定成本的划分（定稿）

利润桥把成本费用分成两类，算法不同，**不能混用**：

| 类别 | 科目 | 算法 |
|---|---|---|
| 变动成本 | 食材成本、优惠及手续费、水电气低值、宣传费用 | 费率变动 × 本期收入 |
| 固定成本 | 工资奖金、宿舍房租、店铺房租、其它费用 | 绝对额变动（取负） |

**边际贡献率**（用于算「收入规模」这一项）：

```
边际贡献率 = (营业收入 − 食材 − 优惠及手续费 − 水电气低值 − 宣传费用) / 营业收入
```

2024-09 实测 = (760 − 195 − 188.4 − 32 − 26.4) / 760 = **41.87%**，与 Excel 利润桥页「按同期 42% 边际贡献率」一致。

> 注意：不能用「1 − 食材成本率 = 74.34%」当边际贡献率——那样收入增长 240 万会算出 +178 万利润，
> 既与 Excel 的 +100 万对不上，也无法让利润桥闭合到 +48.1 万。

## 11. 数据导入、看板与报告口径

### 11.1 导入模板与单位

6 套模板（门店收入、门店客流、渠道收入、产品销售、利润表、线上漏斗）的字段定义唯一来源为 `app/lib/ingestion/templates.ts`。单位与第 9 节样例数据一致：收入 / 成本 / 金额为**万元**，客流为**人次**，客单价与单价为**元**。期间只支持月度 `YYYY-MM`。

### 11.2 校验阈值

| 规则 | 级别 | 阈值 |
|---|---|---|
| 必填、类型、期间格式、负数、主键重复 | 错误（阻断） | — |
| 门店收入 vs 客流 × 客单价 ÷ 10000 | 警告 | 差异率 > 1% |
| 渠道收入合计 vs 门店收入合计 | 警告 | 差异率 > 1% |
| 单店月收入数量级 | 警告 | > 10000 万元 或 < 0.01 万元 |
| 漏斗逐级递减 | 警告 | 曝光 ≥ 访问 ≥ 支付 ≥ 消费 |
| 利润表 9 个科目齐全 | 警告 | 缺任一科目 |

差异率 = |计算值 − 申报值| ÷ |申报值|。常量见 `VALIDATION_THRESHOLDS`。

### 11.3 分析期间与完整度

- **本期** = 数据集中最新的月份；**上年同期** = 本期往前 12 个月；**上月** = 本期往前 1 个月。
- 某模板在某期间「有数据」= 该期间至少一行；利润表要求 9 个科目齐全。
- 页面所需模板在本期或上年同期缺数据，该页显示「数据不完整」。门店收入的上年同期只要求同店有数据（新店上年为 0 属正常）。

### 11.4 数据看板指标

| 指标 | 公式 |
|---|---|
| 门店收入 | Σ 门店收入（门店汇总口径） |
| 客流 | Σ 门店客流（人次） |
| 客单价 | 门店收入 × 10000 ÷ 客流（元/人次，按客流加权） |
| 营业利润 | 营业收入 − 8 项成本费用（利润表口径，与第 7 节一致） |
| 同比 | (本期 − 上年同期) ÷ 上年同期；上年同期无数据或为 0 时为「—」 |
| 环比 | (本期 − 上月) ÷ 上月；上月无数据或为 0 时为「—」 |

### 11.5 分析报告

报告章节的数字全部取自现有 view builder（总览、同店、渠道、产品、结论引擎），不另行计算；生成时整体写入快照，之后数据变化不影响已生成报告。
